1. WHAT IS PYTHON?
------------------
Python is a high-level, interpreted, and object-oriented programming 
language. It was created by Guido van Rossum and released in 1991. 
It is designed to be highly readable, using English keywords frequently 
where other languages use punctuation.

Key Characteristics:
* Interpreted: Code is executed line by line, meaning you do not need 
  to compile it before running.
* Dynamically Typed: You do not need to declare variable types (like int 
  or string) explicitly. Python determines it automatically.
* Cross-Platform: Runs seamlessly on Windows, macOS, Linux, and Raspberry Pi.


2. CORE PYTHON SYNTAX
---------------------

A. Variables and Data Types
Variables are containers for storing data values.

   x = 5               # Integer
   y = 3.14            # Float
   name = "Alice"      # String
   is_active = True    # Boolean

B. Indentation (Crucial in Python)
Python uses whitespace indentation to define blocks of code (like loops or 
functions) instead of curly braces {} used in languages like C++ or Java.

   if x > 0:
       print("x is positive") # Indented with 4 spaces

C. Conditional Statements (if-elif-else)
Used to make decisions based on conditions.

   age = 18
   if age < 13:
       print("Child")
   elif age < 20:
       print("Teenager")
   else:
       print("Adult")

D. Loops
Used to repeat a block of code.

   # For Loop (Iterating over a range)
   for i in range(3):
       print(f"Iteration {i}")

   # While Loop (Runs while condition is true)
   count = 0
   while count < 3:
       print(count)
       count += 1


3. DATA STRUCTURES
------------------

* Lists: Ordered, changeable collections that allow duplicate values.
  fruits = ["apple", "banana", "cherry"]

* Dictionaries: Unordered, changeable collections of key-value pairs.
  user = {"name": "Bob", "age": 25}

* Tuples: Ordered and unchangeable collections.
  coordinates = (10.0, 20.0)

* Sets: Unordered, unindexed, and do not allow duplicate items.
  unique_numbers = {1, 2, 3, 3} # Evaluates to {1, 2, 3}


4. FUNCTIONS & MODULES
----------------------
Functions are blocks of code that run only when called. 

   def greet(user_name):
       return f"Hello, {user_name}!"

   print(greet("World"))

Modules are files containing Python code (libraries) you can import.
   import math
   print(math.sqrt(16)) # Outputs: 4.0


5. WHY IS PYTHON POPULAR?
-------------------------
1. Simple Syntax: Easy to learn for beginners.
2. Massive Community: Millions of developers providing open-source packages.
3. Versatility: Used heavily in:
   - Data Science & Machine Learning (Pandas, TensorFlow)
   - Web Development (Django, Flask)
   - Automation & Scripting
   - Software Testing
